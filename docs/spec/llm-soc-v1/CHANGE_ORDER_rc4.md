# Change order 1.0-rc3 → 1.0-rc4

2026-09-06 · chief-architect · **PROPOSAL BRANCH** `spec/llm-soc-v1-rc4`. rc3 was accepted after RTL/DV/SW three-way review; its architecture is not reopened. This order rules the 27 issues filed by the seven RTL authors, the top integrator and the SW author while implementing rc3 (inputs-rc4/INDEX.md, ISSUE-*.md) and the spec-relevant findings F-01/F-04/F-05/F-06/F-07 of inputs-rc4/integrator-review-01.md. It becomes the baseline only after the rc3 reviewers (RTL, verification, software roles) confirm; until then rc3 remains the implementation contract and every provisional implementation marked `// ISSUE-*: provisional` stands as filed. Dispositions: `spec-gap` (text added), `spec-clear` (no change; quoted text decides), `metadata` (contract.json/traceability only), `rule-level` (AGENTS.md sentence recommended to the orchestrator; not edited here). Two new requirement IDs are added (NPU-09, SYS-13); nothing is renumbered; no CSR offset, address, descriptor layout, numeric format, threshold or ABI major changes.

## Modules that must change (RTL), by this order

npu_ctl (C34 flush output; dma_terminal comment), npu_dot (C34 flush input and behaviour), llm_soc_top (wire C34), sys (RESULT_COMMIT write-0 SLVERR; BOOT_STAGE>4 SLVERR), uart (DIVISOR<2 SLVERR), fabric (ownerless target VALID → reason6). npu_csr: verify LAST_CYCLES untouched on CSR-layer rejection. No change: cpu_bridge, lite_bridge, rom, sram, npu_dma, npu_local, sw/.

## Rule-level recommendations to the orchestrator (AGENTS.md is not edited here)

1. ISSUE-npu_dma-01: "Ports of internal ICD protocols are named `<i_|o_><protocol>_<field>`; AXI ports `<m_|s_>axi_<signal>`; clock/reset `i_clk`, `i_rst_n`; a single-signal protocol whose field name is globally unique may drop the protocol prefix."
2. ISSUE-npu_local-02: "'Every flop resets' applies to control state. A storage array (memory inferred from an unpacked array) whose every read within a reset epoch is preceded by a write may omit reset; the module header must name the array and the spec clause that guarantees write-before-read."

## Not ruled here (not spec defects)

F-02 (ROM IRQ trampoline clobbers t0/t1) is an SW defect against SYS-10 "preserve interrupted integer registers"; the spec is clear, the SW author fixes it. F-03/F-09 (manifest content, .bin gitignore) and F-08 (author trailer attestation) are flow/ledger items for the orchestrator. The lint-recipe defect in ISSUE-top-01's appendix is flow-owned.
