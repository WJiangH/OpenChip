# Software and complete-model contract

Version 1.0-rc3. Host probe is evidence about executable numerical choices, not SoC execution. Model/source/input identities and observed errors are bound in ../../../workloads/llm-soc-v1/README.md.

# §1 SIM-L1 algorithm

**LLM-01:** SIM-L1 shall execute the complete stories260K checkpoint with dim64, hidden172, layers5, query heads8, KV heads4, head_dim8, vocab512, trained sequence capacity512; deployment capacity is512. The tied embedding/head has shape512×64. Layer matrices: Wq64×64, Wk32×64, Wv32×64, Wo64×64, W1/W3 each172×64, W2=64×172. Norm gains are64 per layer norm (two norms/layer) plus64 final. No layer skipping, truncation or host computation of DUT activations is allowed. Every one of the 36 learned-matrix calls per forward (7 per layer+head) shall use NPU opcode1; prefill executes sequential causal token forwards using the same path as decode. Full logits are produced each forward, even when prefill does not sample them. This is intentionally simple, not an optimized prefill-GEMM product claim.

**LLM-02:** Export shall use row-local symmetric INT8 groups of64; last group uses its actual valid length (W2 group lengths64,64,44). For finite FP32 group values v, calculate m=max(abs(v)), scale s=FP32(m/127). For m=0 set s=1 and all q=0. Otherwise each q=clamp(roundAwayFromZero(FP32(v/s)),-127,127), where ties at n+0.5 round to greater absolute integer. Reject NaN/Inf values, and reject a nonzero group whose FP32 scale underflows to zero. Scales are positive finite IEEE754 binary32; there is no zero point. Activations are dynamically quantized with the identical64-element grouping on each matrix input. Padded entries are not included in maxabs or quantization. These rules apply to model export and runtime; checkpoint quantization is part of the deployment model identity.

**LLM-03:** CPU shall reconstruct output row n from group INT32 results as FP32 `y=0; for g ascending: t=FP32(FP32(float32(Y[n,g])*weight_scale[n,g])*activation_scale[g]); y=FP32(y+t)`. Integer-to-float conversion is round-to-nearest ties-to-even; each FP32 operation rounds separately, with no FMA, contraction, fast-math or reassociation. The INT32 grouped dots themselves must be bit exact; no floating tolerance can forgive an integer mismatch. Embeddings are the same quantized tied-head row, reconstructed elementwise FP32(q*s), not the original FP32 row. Scales reside in model or CPU scratch, never in NPU CSRs.

**LLM-04:** CPU software shall implement RMSNorm with epsilon=1e-5, RoPE base10000 with adjacent even/odd coordinates, causal scaled dot-product attention (scale1/sqrt(8)), stable max-subtracted softmax, SiLU gate times up projection, residual additions, final RMSNorm, full logits and greedy argmax with lowest token ID on ties. Query head h uses KV head floor(h/2). KV stores post-RoPE keys and projected values as FP32 in layer-major layout: `K_BASE +4*((layer*512+position)*32+kv_channel)`, with values in a separate identically shaped array. Current K/V is written before attention over positions0..current inclusive. Norm reductions and attention dot/sum reductions iterate coordinates/positions ascending using separate FP32 operations; no FMA. RMSNorm computes sequential sum FP32(x*x), divide by64, add epsilon, sqrt, reciprocal, then FP32(FP32(x*inv)*gain). Softmax computes exp of score-minus-max, sequential ascending sum, then divides each exp by sum. RoPE angle uses `freq=FP32(1/powf(10000,FP32((pair_even_index%8)/8.0f))); angle=FP32(float32(position)*freq)`; sinf/cosf multiply/add as independent FP32 operations. SiLU uses separately rounded reciprocal then multiplication: `d=FP32(1+expf(-x)); inv=FP32(1/d); silu=FP32(x*inv); hidden=FP32(silu*up)`. Direct division x/d is not substituted for x*FP32(1/d); no FMA or reassociation is permitted. Nonfinite intermediates abort with RESULT_CODE=0xD004. Norm/attention/transcendentals are software operations, not implied NPU capabilities.

**LLM-05:** Software shall use binary32 round-to-nearest ties-to-even, no flush-to-zero, no FMA, strict C floating evaluation (no extra precision). `sqrtf/expf/powf/sinf/cosf` shall be within 2 ULP of the correctly rounded binary32 real function for finite inputs used here. Reference reduction order is normative; independent implementation may use a compliant library. Quantized-system acceptance compares each static-matrix INT32 group exactly; reconstructed linear outputs, layer residuals and KV use `abs(dut-ref)<=1e-4+1e-4*abs(ref)` per element; logits use1e-3+1e-4*abs(ref). These are architecture engineering thresholds for cross-library numeric conformance, not observed DUT results or quantization-quality thresholds. If small scalar library differences change later quantized inputs, compare each dot to an independently computed integer reference using its actual submitted legal quantized X and immutable W and separately enforce fixed-reference upstream floating checkpoints. The CPU selected-position integer verifier is defined in LLM-09; the host/DV verifier covers all calls. Greedy generated tokens must match the bound quantized reference exactly for the fixed acceptance input. A failing tolerance or token is a reportable integration failure, never grounds to enlarge limits silently.

# §2 Artifact layout and software ownership

**LLM-06:** The deployed model blob shall occupy 0x80100000..0x80500000 and begin with a64-byte header: u32 magic0x514C4D31, ABI1, dim64, hidden172, layers5, qheads8, kvheads4, vocab512, seq512, group64, tensor_count47, directory_offset64, directory_entry_bytes32, blob_bytes, reserved0, reserved0. Each32-byte tensor entry is eight u32: tensor_id, rows, cols, encoding, data_offset, scale_offset, row_stride, data_bytes. Tensor IDs0=embedding/tied head; for layer l, IDs1+9*l..9+9*l map norm_attn,Wq,Wk,Wv,Wo,norm_ffn,W1,W3,W2; ID46=final norm. Encoding1 groupedI8+FP32 scales for matrices; encoding2 contiguousFP32 for norm gains (rows1 cols64, scale_offset0, row_stride256). Matrix row_stride=round_up(cols,4); data_bytes=rows*row_stride covers only INT8 values and per-row padding, never scales. Matrix scale storage is an independent region of exactly4*rows*ceil(cols/64) bytes, contiguous row-major binary32 words starting at scale_offset. For encoding2, data_bytes=rows*cols*4 and scale-region length=0; scale_offset must be0. Every tensor identity must have the exact rows,cols,encoding and stride fixed by LLM-01/06; mismatched shapes/encoding are rejected. Row padding is included in data_bytes but excluded from quantization and arithmetic. Offsets are blob-relative, 4-aligned, directory order ascending tensor ID. Header and directory reserved fields zero, IDs unique, every data and independent scale region in blob bounds and disjoint from every other data/scale region and the header/directory; tied head is explicitly ID0 reuse without a duplicate entry; malformed blobs abort before dispatch. After validating header length, directory bounds and tensor/region bounds, firmware verifies CRC-32/ISO-HDLC with the SYS-05 polynomial/init/xorout over exactly [0x80100000,0x80100000+validated model.header.blob_bytes), including header,directory,internal padding and data/scales but excluding the model-arena tail. The LLM-08 input-header model_crc32 field is authoritative at runtime; the host run manifest is only its provenance copy. SHA256 binding is host-side artifact provenance in SIM-L1, not a claim of hardware authentication.

**LLM-07:** Arena layout shall be fixed: keys at0x80500000 (327680 bytes), values at0x80550000 (327680 bytes); unused KV arena bytes are zeroed and never read as valid context. Scratch at0x80600000: quantized X buffer4096 bytes, grouped Y at0x80601000 capacity65536 bytes, CPU tensor arena0x80611000..0x80700000 (978944 bytes). No other allocator aliases these regions. Large legal NPU shapes may exceed the model's grouped-Y allocation; driver rejects such software calls or uses another disjoint scratch range, never assumes arbitrary legal hardware shapes fit L1 buffer. KV context beyond512 aborts0xD003 without issuing NPU work for that position.

**LLM-08:** At0x80800000 a128-byte input header shall contain u32 magic0x494C4D31, ABI1, prompt_count32, generate_count16, prompt_offset128, output_offset256, result_offset512, model_crc32, expected_crc32, expected_bytes, then22 zero words. Prompt IDs are32 little-endian u32, each0..511. Output stores16 little-endian u32 IDs. Result structure at+512 is u32 magic0x524C4D31, status(0 running,1 pass,2 fail), last_position, generated_count, failure_code, failing_tensor_id, failing_element_index, then low/high total-cycle count (nine words). CPU checks all layout/count/IDs before processing. Its model_crc32 and expected_crc32 words are the authoritative runtime CRC values; expected_bytes must equal the validated expectation header blob_bytes and be within1MiB. Neither an unspecified runtime manifest nor the host provenance copy overrides these input-header fields. For positions0..31 it consumes the32 input IDs; logits at31 yield generated token0. It then feeds generated token0 at32 and so on through generated token14 at46, yielding token15. For a reproducible48-forward probe it additionally feeds generated token15 at47, checks final logits/KV and emits no seventeenth token. Thus32prefill+16decode forward calls,16 published output tokens,48total forwards are explicit. EOS does not terminate this fixed-size test.

**LLM-09:** CPU shall validate B1 outputs against fixed exact fixtures. For L1, CPU shall validate selected INT32 NPU group results using a separately reviewed scalar integer verifier that reads the actual submitted legal X and immutable W and applies NPU-01, and shall compare selected FP32/model checkpoints and final token sequence to read-only fixed expected artifacts before committing system PASS. The scalar verifier must not write or replace Y, logits, KV or token results; the execution path always consumes actual DMA-written NPU Y. Any mismatch aborts. Verifier cycles are counted separately from inference. This validation recomputation is not a runtime fallback or authorization to bypass the NPU. CPU verification shall cover grouped dots of all36 matrix identities at positions0,31,32,47 using actual input bytes. Fixed expected artifacts shall cover reconstructed outputs and every layer's residual/KV at those positions; all512logits and selected token at each generated step. In addition, independent system DV compares full checkpoints from all48forwards without feeding values into DUT. Expected format is fixed below; manifest binds hashes and independent generator revision. It is forbidden to feed precomputed expected results into the network execution path, replace NPU computation with an accelerator stub, or let the CPU scalar verifier substitute its results for NPU writeback. Failure codes0xD001 manifest/layout,0xD002 NPU,0xD003 context,0xD004 nonfinite,0xD005 integer mismatch,0xD006 float mismatch,0xD007 token mismatch,0xD008 watchdog. RESULT_CODE=0 is only the selected run's complete pass, not security/FPGA/product success.

# §3 ABI and ownership

**LLM-10:** Firmware shall be freestanding RV32IM/ILP32 compiled without compressed or floating hardware instructions, with pinned compiler/libc/libm revisions and flags `-march=rv32im -mabi=ilp32 -ffp-contract=off -fno-fast-math`, fixed linker map, defined startup/BSS/IRQ assembly and compiler-barrier driver API. ELF, flat payload, ROM, model blob, input, expected checkpoint index/data and hashes are separate artifacts. Firmware may supply audited soft-float routines; hardware FPU is not assumed. Standard privileged CSR calls, mret, FENCE.I and an OS are outside the ABI. Counters separately record boot, prefill, decode, CPU quantization/nonlinear, DMA wait and CPU validation cycles; nested counters must declare overlap so their sum is not mislabeled total latency. Report CPU attention fallback time explicitly.


# §4 Independent expectation container

**LLM-11:** The expected blob at0x80700000 shall be bounded to1MiB, have64-byte header words: magic0x454C4D31, ABI1, record_count, directory_offset64, entry_bytes32, blob_bytes, then10zeros. Each32-byte record holds u32 kind, position, identity, element_count, encoding, data_offset, data_bytes, reserved0. Kind1=optional nominal INT32 grouped-dot diagnostic record (not the normative runtime-input integer comparator),2=reconstructed FP32 matrix output,3=FP32 layer residual after FFN,4=FP32 current key vector,5=FP32 current value vector,6=FP32 logits,7=u32 selected token. Encoding1 INT32,2 FP32,3 u32; data_bytes=4*element_count, all offsets4-aligned and in bounds, no overlapping data/directory/header. Sort lexicographically(kind,position,identity); duplicate records reject. identity for kinds1/2 is matrix ordinal0..35: layer*7+offset, offsets Wq,Wk,Wv,Wo,W1,W3,W2=0..6;35=head. identity for kinds3/4/5 is layer0..4, and for6/7 is0. Matrix command TAG=position*36+ordinal. Required counts: kind1=N*ceil(K/64), kind2=N, kind3=64, kind4/5=32, kind6=512, kind7=1. Required positions and coverage are LLM-09; kinds2..7 are mandatory at their required positions, while kind1 is optional and may differ when a legal upstream FP32 difference changes quantization. Such differences do not excuse a mismatch against the actual-X/W scalar verifier. kind7 records map generated tokens0..15 to positions31..46. Missing mandatory records fail before inference. Validate all lengths and ranges before CRC reads. Reuse SYS-05 CRC-32/ISO-HDLC parameters over exactly [0x80700000,0x80700000+validated expected.header.blob_bytes), including header,directory,internal padding and record data, excluding expected-arena tail. Require LLM-08 input expected_bytes==expected.header.blob_bytes and compare CRC to its authoritative expected_crc32 word. Header, records and CRC must pass before use. B1 expected records use a separate boot-selected fixture manifest and exact group results, never masquerade as model tensor records.


# §5 Complete forward equations

**LLM-12:** One forward at position p with token t shall execute the following graph; every linear below is LLM-02/03 W8A8 NPU grouped-dot plus CPU postscale, every scalar operation follows LLM-04/05. These equations fix data dependence and ordering, not a license for CPU learned-matrix fallback.

1. `x = dequantize(embedding[t,:])` (64FP32 elements).
2. For layer l=0..4 in ascending order, retain `residual0=x`; set `a=RMSNorm(x,norm_attn[l])`.
3. `q=linear(Wq[l],a)`, `k=linear(Wk[l],a)`, `v=linear(Wv[l],a)` in that command order. Apply RoPE(p) to q and k only; v remains unrotated. Query q[h,d]=q[8*h+d], h0..7,d0..7; k/v[hkv,d]=k/v[8*hkv+d], hkv0..3.
4. Store rotated k and unrotated v to this layer's current KV rowp before reading causal attention. For each query head h0..7 and time j0..p, `score[j]=FP32(sum_d_ascending FP32(q[h,d]*K[l,j,floor(h/2),d]) / sqrtf(8))`, with FP32 rounding at every product and accumulation. Softmax over j0..p yields probability[j] using LLM-04. For each d0..7, `z[8*h+d]=sum_j_ascending FP32(probability[j]*V[l,j,floor(h/2),d])` with FP32 accumulation. Concatenate heads in increasing h; no permutation. No future context contributes.
5. `o=linear(Wo[l],z)`; `x=FP32(residual0+o)` elementwise. Retain this post-attention `residual1=x`, then `b=RMSNorm(x,norm_ffn[l])`.
6. `gate=linear(W1[l],b)` then `up=linear(W3[l],b)`. `hidden[i]=FP32(SiLU(gate[i])*up[i])` for i0..171; SiLU acts on W1, not W3.
7. `down=linear(W2[l],hidden)`; `x=FP32(residual1+down)` elementwise. This x is the layer residual checkpoint kind3; proceed to l+1.
8. After layer4, `final=RMSNorm(x,norm_final)` then `logits=linear(embedding,final)` using tied weights. Argmax/tokens/KV forward count follow LLM-08. Neither intermediate residual source is replaced by a normalized activation.
